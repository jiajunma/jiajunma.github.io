Root Data

A root datum is a combinatorial quadruple that encodes the symmetry structure of a (split) reductive group. It is the algebraic-geometric analogue of an abstract root system, refined to keep track of characters and cocharacters separately.

Definition

A root datum is a quadruple \((X, \Phi, X^\vee, \Phi^\vee)\) where:

  • \(X\) and \(X^\vee\) are finitely generated free \(\mathbb{Z}\)-modules with a perfect pairing \[ \langle -, - \rangle : X \times X^\vee \to \mathbb{Z}; \]
  • \(\Phi \subseteq X\) is a finite subset, the roots;
  • \(\Phi^\vee \subseteq X^\vee\) is a finite subset, the coroots;
  • there is a bijection \(\Phi \leftrightarrow \Phi^\vee\), \(\alpha \leftrightarrow \alpha^\vee\) satisfying:
  • \(\langle \alpha, \alpha^\vee \rangle = 2\);
  • the reflection \(s_\alpha : X \to X\) defined by \(s_\alpha(x) = x - \langle x, \alpha^\vee \rangle \alpha\) permutes \(\Phi\) (and the dual reflection on \(X^\vee\) permutes \(\Phi^\vee\)).

If \(\Phi\) spans \(X \otimes \mathbb{Q}\), the root datum is called semisimple; otherwise the orthogonal complement of \(\Phi\) in \(X\) records the central torus.

The Weyl group

The reflections \(s_\alpha\) for \(\alpha \in \Phi\) generate a finite group \(W \subseteq \operatorname{Aut}(X)\), the Weyl group. The pair \((W, \{s_\alpha\}_{\alpha \in \Phi})\) is generated by simple reflections (once a base is chosen) and forms a Coxeter system.

From reductive groups

For a split connected reductive group \(G\) over a field \(k\) with split maximal torus \(T\):

  • \(X = X^*(T) = \operatorname{Hom}(T, \mathbb{G}_m)\);
  • \(X^\vee = X_*(T) = \operatorname{Hom}(\mathbb{G}_m, T)\);
  • \(\Phi\) = the nonzero weights of \(T\) acting on \(\operatorname{Lie}(G)\);
  • \(\Phi^\vee\) = the coroots arising from the SL_2-triples attached to each root.

This is the canonical example: the root datum of \((G, T)\) is independent (up to isomorphism) of the choice of \(T\), and only the isomorphism class of \(G\) matters.

Examples

\(\operatorname{GL}_n\)

  • \(X = \mathbb{Z}^n\) with standard basis \(\varepsilon_1, \dots, \varepsilon_n\);
  • \(X^\vee = \mathbb{Z}^n\) with dual basis;
  • \(\Phi = \{\varepsilon_i - \varepsilon_j : i \ne j\}\);
  • \(\Phi^\vee = \{\varepsilon_i^\vee - \varepsilon_j^\vee\}\) with the obvious bijection;
  • \(W = S_n\), permuting the \(\varepsilon_i\).

\(\operatorname{SL}_n\)

\(X = \mathbb{Z}^n / \mathbb{Z}(1, 1, \dots, 1)\) (the quotient identifying constant vectors with zero); \(X^\vee\) is the kernel of the sum map. Roots and coroots descend from \(\operatorname{GL}_n\).

\(\operatorname{PGL}_n\)

\(X = \{(a_1, \dots, a_n) \in \mathbb{Z}^n : \sum a_i = 0\}\) (the kernel of the sum map); \(X^\vee = \mathbb{Z}^n / \mathbb{Z}(1, \dots, 1)\). This is the dual of the \(\operatorname{SL}_n\) root datum.

Tori

If \(\Phi = \emptyset\), the root datum is just a pair \((X, X^\vee)\) of dual lattices — and the corresponding group is a torus.

Isogeny classes

A morphism of root data is a \(\mathbb{Z}\)-linear map preserving roots and coroots. Two root data are isogenous if they share the same \(\Phi\) in \(X \otimes \mathbb{Q}\), differing only in the lattice \(X\) between the root lattice \(\mathbb{Z}\Phi\) and the weight lattice \(P = \{x \in X \otimes \mathbb{Q} : \langle x, \alpha^\vee \rangle \in \mathbb{Z}\}\).

Within a semisimple isogeny class:

  • the simply connected form has \(X = \mathbb{Z}\Phi^\vee\)'s dual lattice = \(P\) (largest \(X\), e.g.\ \(\operatorname{SL}_n\));
  • the adjoint form has \(X = \mathbb{Z}\Phi\) (smallest \(X\), e.g.\ \(\operatorname{PGL}_n\)).

The quotient \(P/\mathbb{Z}\Phi\) is the fundamental group of the adjoint form; for \(\operatorname{PGL}_n\) it is \(\mathbb{Z}/n\).

Duality

The dual root datum is \[ (X, \Phi, X^\vee, \Phi^\vee)^\vee \;=\; (X^\vee, \Phi^\vee, X, \Phi). \] Under the classification of reductive groups, duality of root data corresponds to Langlands duality of reductive groups. See based root data for the classification statement.

Relation to abstract root systems

Forgetting the lattice and keeping only \(\Phi \subseteq X \otimes \mathbb{R}\) recovers the classical notion of a root system (Bourbaki). The lattice refinement is what distinguishes \(\operatorname{SL}_n\) from \(\operatorname{PGL}_n\): both have the same \(\Phi\) of type \(A_{n-1}\) but different \(X\).
