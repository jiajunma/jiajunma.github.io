Root Systems

A root system is a finite subset of a Euclidean vector space satisfying reflection-stability axioms. Root systems are the combinatorial backbone of Lie theory: they classify finite-dimensional semisimple Lie algebras, simply connected simple algebraic groups, and compact Lie groups.

Definition

A root system in a finite-dimensional real Euclidean space \(V\) (with inner product \((-, -)\)) is a finite subset \(\Phi \subseteq V\) satisfying:

(R1) \(\Phi\) spans \(V\) and \(0 \notin \Phi\);

(R2) For each \(\alpha \in \Phi\), the only scalar multiples of \(\alpha\) in \(\Phi\) are \(\pm \alpha\);

(R3) For each \(\alpha \in \Phi\), the reflection \[ s_\alpha(x) \;=\; x - \frac{2(x, \alpha)}{(\alpha, \alpha)} \alpha \] permutes \(\Phi\);

(R4) For all \(\alpha, \beta \in \Phi\): \(\frac{2(\alpha, \beta)}{(\beta, \beta)} \in \mathbb{Z}\).

A root system is reduced if (R2) holds; some sources allow non-reduced root systems (e.g.\ \(BC_n\), with both \(\alpha\) and \(2\alpha\) appearing).

The Weyl group

The group \(W \subseteq O(V)\) generated by \(\{s_\alpha : \alpha \in \Phi\}\) is the Weyl group of \(\Phi\) — a finite reflection group. It acts simply transitively on the chambers of the complement of the hyperplane arrangement \(\bigcup_\alpha \alpha^\perp\).

Bases and positivity

A base (or simple system) is a subset \(\Delta \subseteq \Phi\) such that: - \(\Delta\) is a basis of \(V\); - Every \(\alpha \in \Phi\) is a non-negative or non-positive integer combination of \(\Delta\).

Choosing a base is equivalent to choosing a Weyl chamber.

Given \(\Delta\), the positive roots \(\Phi^+\) are the non-negative combinations; \(\Phi^- = -\Phi^+\). Every base gives a decomposition \(\Phi = \Phi^+ \sqcup \Phi^-\).

Cartan matrix

For a base \(\Delta = \{\alpha_1, \dots, \alpha_r\}\), the Cartan matrix is \[ C \;=\; (c_{ij}), \qquad c_{ij} = \frac{2(\alpha_i, \alpha_j)}{(\alpha_j, \alpha_j)}. \]

It encodes the angles and length ratios of simple roots; the off-diagonal entries are in \(\{0, -1, -2, -3\}\).

Dynkin diagrams

The Dynkin diagram of a root system is a graph with: - vertices = simple roots; - edges connecting \(\alpha_i, \alpha_j\) labelled by \(c_{ij} c_{ji} \in \{0, 1, 2, 3\}\) (no edge if \(0\), single if \(1\), double if \(2\), triple if \(3\)); - arrows pointing from long roots to short roots (in non-simply-laced types).

Classification

Theorem (Killing-Cartan, completed by Dynkin). Connected Dynkin diagrams of finite-type root systems are: \[ A_n \;(n \ge 1), \quad B_n \;(n \ge 2), \quad C_n \;(n \ge 3), \quad D_n \;(n \ge 4), \] \[ E_6, \quad E_7, \quad E_8, \quad F_4, \quad G_2. \]

Any root system decomposes uniquely as an orthogonal direct sum of irreducible root systems (connected Dynkin components).

Examples

\(A_{n-1}\)

\(V \subseteq \mathbb{R}^n\) the hyperplane \(\sum x_i = 0\); \(\Phi = \{e_i - e_j : i \ne j\}\); \(W = S_n\) acting by permutation.

\(B_n\)

\(V = \mathbb{R}^n\); \(\Phi = \{\pm e_i \pm e_j : i < j\} \cup \{\pm e_i\}\); \(W = \{\pm 1\}^n \rtimes S_n\) (signed permutations).

\(C_n\) (dual of \(B_n\))

\(\Phi = \{\pm e_i \pm e_j : i < j\} \cup \{\pm 2 e_i\}\).

\(D_n\)

\(\Phi = \{\pm e_i \pm e_j : i < j\}\); only "two-letter" roots, simply laced.

\(G_2\)

Rank 2; 12 roots; two root lengths in ratio \(\sqrt{3} : 1\); \(W\) = dihedral of order 12.

Length-2 chains and structure

If \(\alpha, \beta \in \Phi\) are non-proportional roots, the string \(\beta - p\alpha, \dots, \beta + q\alpha\) of roots (integers \(p, q \ge 0\)) satisfies \[ p - q \;=\; \frac{2(\beta, \alpha)}{(\alpha, \alpha)} \;\in\; \{-3, -2, -1, 0, 1, 2, 3\}. \] Strings have length \(\le 4\). This is the fundamental combinatorial constraint underlying the entire classification.

Coroots and root datum

For \(\alpha \in \Phi\), the coroot is \(\alpha^\vee = 2\alpha / (\alpha, \alpha) \in V^*\). The set \(\Phi^\vee = \{\alpha^\vee : \alpha \in \Phi\}\) is again a root system (the dual root system).

A root system together with a lattice \(X\) with \(\mathbb{Z}\Phi \subseteq X \subseteq P\) (weight lattice) refines a root system to a root datum.
