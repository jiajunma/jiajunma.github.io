Lean Formalization Plan for the Weil-Index Trivialization Theorem

This proof-plan node breaks Milestone A — the Lean formalization of Orthogonality and Trivialization of the Change-of-Lagrangian Cocycle — into named Lean declarations with their signatures and dependencies, in topological order.

Goal and scope

Formalize the statements and proofs of Orthogonality and Trivialization of the Change-of-Lagrangian Cocycle over an abstract finite symplectic $k$-space with a chosen nontrivial central character $\xi\colon k\to R^{\times}$, $\operatorname{char}R\neq p$, in Lean 4 + Mathlib 4, reusing the existing lean/FiniteWeilCocycle.lean (abstract scalar cocycle) and lean/FiniteQuadraticWeilIndex.lean (Gauss-sum orthogonality).

Out of scope for this milestone: Schur on the Heisenberg irreducible (Step (II)/(2) of the theorem will be derived directly from orthogonality without invoking Stone–von Neumann), Gérardin's linearization (deferred to later milestone), spherical-building mixed models (deferred).

Step list (topological order)

Layer L2: foundational structures

  1. ThetaType.FiniteWeil.SymplecticSpace — the underlying $(E,j)$.

```lean variable (k : Type*) [Field k] [Fintype k] [Fact (Odd (Fintype.card k))]

structure SymplecticSpace where E : Type* [addCommGroup : AddCommGroup E] [module : Module k E] [fintype : Fintype E] [decEq : DecidableEq E] j : E →ₗ[k] E →ₗ[k] k skew : ∀ x y, j x y = - j y x nondeg : ∀ x, (∀ y, j x y = 0) → x = 0

noncomputable def i (S : SymplecticSpace k) : S.E →ₗ[k] S.E →ₗ[k] k := -- j/2 ```

Deps: none. Difficulty: low.

  1. ThetaType.FiniteWeil.Isotropic — isotropic and Lagrangian subspaces.

```lean def IsIsotropic (S : SymplecticSpace k) (L : Submodule k S.E) : Prop := ∀ x ∈ L, ∀ y ∈ L, S.j x y = 0

structure Lagrangian (S : SymplecticSpace k) where L : Submodule k S.E isotropic : IsIsotropic S L maximal : ∀ M : Submodule k S.E, L ≤ M → IsIsotropic S M → L = M ```

Deps: SymplecticSpace. Difficulty: low.

  1. ThetaType.FiniteWeil.HeisenbergGroup — $H(E,j)=E\times k$ with the cocycle.

```lean structure HeisenbergGroup (S : SymplecticSpace k) where w : S.E z : k

instance : Group (HeisenbergGroup S) where mul x y := ⟨x.w + y.w, x.z + y.z + S.i x.w y.w⟩ -- etc. ```

Deps: SymplecticSpace. Difficulty: low (a calculation). State: group axioms via decide over the cocycle.

Layer L2 (continued): Schrödinger model

  1. ThetaType.FiniteWeil.SchroedingerModel — $\mathcal S_L=\{\varphi\colon E\to R\mid\varphi(v+a)=\xi(i(v,a))\varphi(v),\ a\in L\}$.

```lean variable (R : Type*) [Field R] [CharZero R] -- or appropriate splitting hypothesis variable (ξ : AddChar k R) (hξ : ξ ≠ 0)

def SchroedingerModel (L : Lagrangian S) : Submodule R (S.E → R) := { φ | ∀ v a, a ∈ L.L → φ (v + a) = ξ (S.i v a) * φ v } ```

Deps: Lagrangian, HeisenbergGroup. Difficulty: low.

  1. ThetaType.FiniteWeil.SchroedingerModel.heisAction — $\eta_\xi$ action on $\mathcal S_L$.

```lean def heisAction (h : HeisenbergGroup S) : SchroedingerModel R ξ L →ₗ[R] SchroedingerModel R ξ L := -- (η_ξ(u,s) φ)(v) = ξ(s + i(u,v)) * φ(v - u) fun ⟨φ, hφ⟩ => ⟨fun v => ξ (h.z + S.i h.w v) * φ (v - h.w), by …⟩

theorem heisAction_isRep : MonoidHom (HeisenbergGroup S) (SchroedingerModel R ξ L →ₗ[R] SchroedingerModel R ξ L) := … ```

Deps: (4). Difficulty: medium (preserve covariance; group homomorphism check).

Layer L2: intertwiner

  1. ThetaType.FiniteWeil.FIntertwiner — $\mathcal F_{L,L'}\colon\mathcal S_{L'}\to\mathcal S_L$ by the sum formula (matching the convention of Compatible System of Schrödinger-Model Intertwiners over a Finite Field).

lean noncomputable def FIntertwiner (L L' : Lagrangian S) : SchroedingerModel R ξ L' →ₗ[R] SchroedingerModel R ξ L := fun ⟨φ, hφ⟩ => ⟨fun v => ∑ a ∈ Finset.image Quotient.mk (L.L ⊓ L'.L) (L.L.toAddSubgroup.quotient _).toFinset, ξ (S.i (Quotient.out a) v) * φ (v + Quotient.out a), by …⟩

Or, equivalently, using the manifestly representative-free averaged form $\mathcal F_{L,L'}\varphi=|L\cap L'|^{-1}\sum_{a\in L}\xi(i(a,v))\varphi(v+a)$.

Deps: (4). Difficulty: medium (coset-sum well-definedness).

  1. FIntertwiner_lands — the output is in $\mathcal S_L$.

lean theorem FIntertwiner_lands (L L' : Lagrangian S) (φ : SchroedingerModel R ξ L') : ∀ v b, b ∈ L.L → (FIntertwiner L L' φ).1 (v + b) = ξ (S.i v b) * (FIntertwiner L L' φ).1 v

Deps: (6). Difficulty: medium (reindex; the $i(a,b)=0$ and $i(b,b)=0$ for $a,b\in L$ algebra).

  1. FIntertwiner_intertwines — $\mathcal F$ commutes with $\eta_\xi$.

lean theorem FIntertwiner_intertwines (L L' : Lagrangian S) (h : HeisenbergGroup S) (φ : SchroedingerModel R ξ L') : FIntertwiner L L' (heisAction h φ) = heisAction h (FIntertwiner L L' φ)

Deps: (5), (6). Difficulty: medium.

Layer L3: orthogonality and cocycle

  1. d_LL — the index $d_{L,L'}=m-\dim_k(L\cap L')$ and the orthogonality scalar.

lean noncomputable def d_LL (L L' : Lagrangian S) : ℕ := (Fintype.card k) ^ ((FiniteDimensional.finrank k L.L) - (FiniteDimensional.finrank k (L.L ⊓ L'.L)))

Deps: Lagrangian. Difficulty: low.

  1. FIntertwiner_orthogonality — the load-bearing computation.

    lean theorem FIntertwiner_orthogonality (L L' : Lagrangian S) : FIntertwiner L L' ∘ₗ FIntertwiner L' L = d_LL L L' • LinearMap.id

    Deps: (6)–(8), and the character-sum machinery from FiniteQuadraticWeilIndex.lean. Difficulty: the hard step. Proof structure: (a) double sum + reindex; (b) inner character sum over $L/(L\cap L')$ vanishes off the trivial coset (use character_sum_eq_zero_of_ne_zero from FiniteQuadraticWeilIndex.lean); (c) surviving term gives $q^{d}\cdot\varphi(v)$.

  2. gamma_def — define the cocycle scalar from composition.

    lean noncomputable def gamma (L L' L'' : Lagrangian S) : R := -- the unique scalar γ ∈ R^× with F(L,L') ∘ F(L',L'') = γ • F(L,L''). -- Construct via: compose with F(L'',L) (which gives q^{d_{L,L''}} • F(L',L'')), -- then the scalar is q^{-d_{L,L''}} times the composed thing. …

    Deps: (10). Difficulty: low-medium. Uses orthogonality to extract the scalar without invoking Schur.

  3. gamma_is_2cocycle — associativity of composition gives the cocycle identity.

    lean theorem gamma_is_2cocycle : IsTransitionCocycle (gamma S R ξ : ι → ι → ι → R)

    where ι = Lagrangian S and IsTransitionCocycle is from FiniteWeilCocycle.lean.

    Deps: (11). Difficulty: medium (direct associativity argument).

Layer L3 → L0: instance of the abstract trivialization

  1. abstractTransitionSystem — package the concrete data as AbstractTransitionSystem.

    lean noncomputable def abstractTransitionSystem : AbstractTransitionSystem (Lagrangian S) R := { Hom := fun L L' => SchroedingerModel R ξ L' →ₗ[R] SchroedingerModel R ξ L comp := fun f g => f.comp g smul := fun a f => a • f F := FIntertwiner gamma := gamma comp_F := … smul_F_cancel := … … }

    Deps: (1)–(12). Difficulty: low (assembly).

  2. weil_index_trivialization — the main theorem, via the abstract machinery.

    lean theorem weil_index_trivialization (L₀ : Lagrangian S) : ∃ (c : Lagrangian S → Lagrangian S → R), (∀ L L' L'', gamma L L' L'' = c L L' * c L' L'' * (c L L'')⁻¹) ∧ (∀ L, c L L = 1) := by let T := abstractTransitionSystem (S := S) (R := R) (ξ := ξ) have hcoc := T.gamma_isTransitionCocycle refine ⟨fun L L' => gamma L L' L₀, ?_, ?_⟩ · exact fun L L' L'' => cocycle_eq_base_coboundary ⟨L₀⟩ hcoc · intro L; … -- F(L,L) = id, so γ(L,L,L₀) = 1

    Deps: (13) plus the existing FiniteWeilCocycle lemmas. Difficulty: low (mostly assembly).

Total cost and milestones

  • Layer L2 (steps 1–6, structural): ~600–1000 LOC. Single morning–afternoon push once the typeclasses settle.
  • Layer L2-extension (steps 7–8): ~200 LOC. Algebra.
  • Layer L3 (steps 9–12): the orthogonality proof (step 10) is the time sink; the rest is ~200 LOC.
  • L3 → L0 hookup (steps 13–14): trivial assembly given the above.

Milestone A complete = weil_index_trivialization is a proven Lean theorem matching the md statement.

What this milestone deliberately omits

  • The Schur step (uniqueness of gamma up to scalar via $\operatorname{End}_H=R$) is replaced by an explicit construction in step 11. Stone–von Neumann is not formalized.
  • The canonical / equivariant version via Gérardin's linearization is deferred to Milestone B.
  • The spherical-building mixed-model statement Compatible System of Mixed Schrödinger Models on the Spherical Building is Milestone C; it reuses Milestone A through the Lagrangian collapse.
