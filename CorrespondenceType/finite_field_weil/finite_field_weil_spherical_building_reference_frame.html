Lagrangian Reference Frame for the Spherical-Building Compatible System

This node makes precise the claim that, once a base Lagrangian $L_0$ is fixed, the spherical-building compatible system of Compatible System of Mixed Schrödinger Models on the Spherical Building becomes fully determined by the Lagrangian compatible system Compatible System of Schrödinger-Model Intertwiners over a Finite Field together with an auxiliary facet-to-Lagrangian-extension assignment. There is no extra structure on top of the Lagrangian system; the spherical-building system is its reorganization through the building.

Motivation

Each facet $\mathbf F$ of the spherical building has a mixed model $\mathcal M_{\mathbf F}$ that is abstractly a copy of the unique irreducible Weil representation $V$ (Stone–von Neumann). To write any element of $V$ concretely one needs a Lagrangian-style polarization; the spherical-building node solves this by choosing a Lagrangian extension $L_{\mathbf F}\supseteq C_r^{\mathbf F}$ at every facet. This raises the question

How does one choose the $L_{\mathbf F}$ canonically?

The answer recorded here: one cannot choose canonically per facet, but one can fix a single global Lagrangian $L_0$ and translate every mixed model into $\mathcal S_{L_0}$ using the Lagrangian intertwiners from compatible_lagrangian_transition_system. In this $L_0$-reference frame, the spherical-building compatible system collapses to identities, and the auxiliary $L_{\mathbf F}$ choices become invisible (their effect cancels in any computation closed within the $L_0$-frame).

Setup (recalled)

As in Compatible System of Mixed Schrödinger Models on the Spherical Building: $(E,j)$ nondegenerate symplectic over $\mathbb F_q$ ($q$ odd), $H(E,j)$ Heisenberg group, $G=\operatorname{Sp}(E,j)$, $\xi\colon k\to R^{\times}$ nontrivial. For each isotropic flag $\mathbf F$ with maximal element $C_r$, choose a Lagrangian extension $L_{\mathbf F}\supseteq C_r$. By Lagrangian collapse,

$$\mathcal M_{\mathbf F}\ =\ \mathcal S_{L_{\mathbf F}}\qquad(\text{induction-in-stages identification}),$$

and the spherical-building cocycle satisfies

$$\widetilde T_{\mathbf F,\mathbf E}\ =\ \widetilde{\mathcal F}_{L_{\mathbf F},L_{\mathbf E}}\qquad\colon\mathcal S_{L_{\mathbf E}}\to\mathcal S_{L_{\mathbf F}}.$$

Fix one further Lagrangian $L_0$ of $E$ (the reference Lagrangian), used both as the trivialization base of $\widetilde{\mathcal F}$ and as the target of all translations below.

The translator $\Phi_{\mathbf F}$

For each facet $\mathbf F$ with chosen extension $L_{\mathbf F}$, define

$$\boxed{\ \Phi_{\mathbf F}\ :=\ \widetilde{\mathcal F}_{L_0,L_{\mathbf F}}\ \colon\ \mathcal M_{\mathbf F}=\mathcal S_{L_{\mathbf F}}\overset{\sim}{\longrightarrow}\mathcal S_{L_0}.\ }$$

This is not a new object: it is the Lagrangian intertwiner from compatible_lagrangian_transition_system, specialized so that one slot is $L_0$. Properties inherited from there:

  • $\Phi_{\mathbf F}$ is an $H(E,j)$-equivariant isomorphism.
  • $\Phi_{\mathbf F}$ is canonical given $L_0$ and the auxiliary $L_{\mathbf F}$.
  • Different choices of $L_{\mathbf F}$ give explicitly related translators (§ Change of auxiliary, below).

Main theorem (compatibility in the reference frame)

For all facets $\mathbf F, \mathbf E$ with chosen extensions $L_{\mathbf F}, L_{\mathbf E}$,

$$\boxed{\ \Phi_{\mathbf F}\circ\widetilde T_{\mathbf F,\mathbf E}\ =\ \Phi_{\mathbf E}\ \colon\ \mathcal M_{\mathbf E}\to\mathcal S_{L_0}.\ }$$

Equivalently,

$$\Phi_{\mathbf F}\circ\widetilde T_{\mathbf F,\mathbf E}\circ\Phi_{\mathbf E}^{-1}\ =\ \mathrm{id}_{\mathcal S_{L_0}}.$$

Proof

Substitute the Lagrangian-collapse identifications:

$$\Phi_{\mathbf F}\circ\widetilde T_{\mathbf F,\mathbf E}\ =\ \widetilde{\mathcal F}_{L_0,L_{\mathbf F}}\circ\widetilde{\mathcal F}_{L_{\mathbf F},L_{\mathbf E}}.$$

By the Lagrangian cocycle in compatible_lagrangian_transition_system,

$$\widetilde{\mathcal F}_{L_0,L_{\mathbf F}}\circ\widetilde{\mathcal F}_{L_{\mathbf F},L_{\mathbf E}}\ =\ \widetilde{\mathcal F}_{L_0,L_{\mathbf E}}\ =\ \Phi_{\mathbf E}.\qquad\square$$

Interpretation. In the $L_0$-reference frame, the entire spherical-building compatible system is the trivial system $\{\mathrm{id}_{\mathcal S_{L_0}}\}$. The non-triviality of $\widetilde T$ lives entirely in the translators $\Phi_{\mathbf F}$, which are themselves nothing but Lagrangian intertwiners.

Change of auxiliary $L_{\mathbf F}$

Replacing $L_{\mathbf F}$ by $L_{\mathbf F}'\supseteq C_r^{\mathbf F}$ changes the translator by

$$\boxed{\ \Phi_{\mathbf F}'\ =\ \Phi_{\mathbf F}\circ\widetilde{\mathcal F}_{L_{\mathbf F},L_{\mathbf F}'}\ \colon\ \mathcal S_{L_{\mathbf F}'}\to\mathcal S_{L_0}.\ }$$

Proof. Both sides are equal to $\widetilde{\mathcal F}_{L_0,L_{\mathbf F}'}$ by the Lagrangian cocycle:

$$\widetilde{\mathcal F}_{L_0,L_{\mathbf F}}\circ\widetilde{\mathcal F}_{L_{\mathbf F},L_{\mathbf F}'}\ =\ \widetilde{\mathcal F}_{L_0,L_{\mathbf F}'}.\qquad\square$$

Interpretation. The "auxiliary choice gauge" is concretely the explicit map $\widetilde{\mathcal F}_{L_{\mathbf F},L_{\mathbf F}'}$ — not a mysterious or free scalar. Two different auxiliary choices are related by a known, computed Lagrangian intertwiner. The freedom is real, but it is fully resolved.

Change of reference $L_0$

Replacing the reference $L_0$ by $L_0'$ changes every translator by left-multiplication with a single Lagrangian intertwiner:

$$\boxed{\ \Phi_{\mathbf F}^{(L_0')}\ =\ \widetilde{\mathcal F}_{L_0',L_0}\circ\Phi_{\mathbf F}^{(L_0)}\ \colon\ \mathcal S_{L_{\mathbf F}}\to\mathcal S_{L_0'}.\ }$$

Proof. $\Phi_{\mathbf F}^{(L_0')}=\widetilde{\mathcal F}_{L_0',L_{\mathbf F}}=\widetilde{\mathcal F}_{L_0',L_0}\circ\widetilde{\mathcal F}_{L_0,L_{\mathbf F}}=\widetilde{\mathcal F}_{L_0',L_0}\circ\Phi_{\mathbf F}^{(L_0)}$ by the cocycle. $\square$

Interpretation. Different reference frames give equivalent descriptions, with the equivalence given by the single Lagrangian intertwiner $\widetilde{\mathcal F}_{L_0',L_0}$. This is the only choice in the entire setup: $L_0$ itself.

Consequence: the spherical-building compatible system has no content beyond the Lagrangian system

Combining the three boxed identities, the data of a "compatible realization of the Weil representation on the spherical building" is fully encoded by:

  1. The Lagrangian compatible system $\{\widetilde{\mathcal F}_{L,L'}\}_{L,L'\text{ Lagrangian}}$ — already in compatible_lagrangian_transition_system.
  2. A choice $L_0$ of reference Lagrangian — single global choice.
  3. An auxiliary facet-to-Lagrangian-extension assignment $\mathbf F\mapsto L_{\mathbf F}\supseteq C_r^{\mathbf F}$ — the "scaffolding" that becomes invisible in the $L_0$-frame.

The spherical-building cocycle $\widetilde T$ is then a derived object: it equals $\widetilde{\mathcal F}_{L_{\mathbf F},L_{\mathbf E}}$ via Lagrangian collapse, and the change-of-$L_{\mathbf F}$ and change-of-$L_0$ formulas above account for all the "gauge" content discussed in spherical_building_mixed_model_compatible_system. Nothing new is introduced by passing from Lagrangians to facets; the spherical-building perspective only reorganizes the Lagrangian system via the building structure.

What this resolves

The previously-vague phrase "Lagrangian assignment is a gauge, not a canonical choice" of spherical_building_mixed_model_compatible_system is now made concrete:

Word in the original Concrete object here
"compatible realization of $V$" translator $\Phi_{\mathbf F}=\widetilde{\mathcal F}_{L_0,L_{\mathbf F}}$
"gauge of $L_{\mathbf F}$ choice" the intertwiner $\widetilde{\mathcal F}_{L_{\mathbf F},L_{\mathbf F}'}$
"canonical up to gauge" canonical given $L_0$; change-of-$L_0$ via $\widetilde{\mathcal F}_{L_0',L_0}$
"compatible system widetildeT" identity, in the $L_0$-frame

The "gauge" is not mysterious freedom — it is a concrete, computable Lagrangian intertwiner. The mathematics has no unexplained scalars.
