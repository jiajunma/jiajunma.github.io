$G$-equivariant sheaves and cosheaves

Assume $G$ acts cellularly on $X$ (see Locally finite regular CW complex with cellular G-action).

Definition. A $G$-equivariant $\mathscr{C}$-valued sheaf on $X$ is a pair $(V,a)$ where $V$ is a sheaf on $X$ and $a$ assigns to each $g \in G$ a morphism $a(g) \in \Hom(V, g^*V)$ satisfying $a(gh) = (h^* a(g)) \circ a(h)$, with $g^*V$ obtained by post-composing $V$ with $g : ]X[ \to ]X[$.

Cellular form. Equivalently, a $G$-equivariant sheaf is a collection

  • $V_F$, one object of $\mathscr{C}$ for each cell $F \in [\![X]\!]$;
  • a restriction $r^V_{E,F} : V_E \to V_F$ for each $E \preceq F$;
  • an isomorphism $a^V_{g,F} : V_F \to V_{gF}$ for each $g \in G$, $F \in [\![X]\!]$,

subject to four compatibilities:

  • $r^V_{E,E} = \id_{V_E}$;
  • $r^V_{E,F} \circ r^V_{D,E} = r^V_{D,F}$ for $D \preceq E \preceq F$;
  • $a^V_{g,hF} \circ a^V_{h,F} = a^V_{gh,F}$;
  • $a^V_{g,F} \circ r^V_{E,F} = r^V_{gE,gF} \circ a^V_{g,E}$ (equivariance of restrictions).

A $G$-equivariant cosheaf has the analogous data with restriction directions reversed.

Notation. We write $\Sh_G(X,R)$ (resp.\ $\Cosh_G(X,R)$) for $G$-equivariant $R$-modules; for the trivial group we recover $\Sh(X,R) = \Sh_{\{e\}}(X,R)$.

Lean formalization

Naming convention: functor form (Sheaf, Cosheaf) vs object form (Sheaf', Cosheaf')

Two equivalent presentations of the underlying (non-equivariant) (co)sheaf exist in the paper, and the Lean library encodes both under distinct names:

  • Sheaf X C, Cosheaf X C (no prime) — functor form. Literal X ⥤ C and Xᵒᵖ ⥤ C, introduced as abbrevs. All of Mathlib's CategoryTheory.Functor API applies directly with no wrapping. This is the canonical form used throughout the library — GEquivariantSheaf, GEquivariantCosheaf, GEquivCosheaf', GEquivCosheaf'.toFunctor, and the reduction chain (Reduction of G-equivariant cosheaves to a QFD) all sit on top of it.

  • Sheaf' X C, Cosheaf' X C (with prime) — object form. Sheaf7 §2.2's classical $(V, r)$-pair form as a structure with fields obj : X → C and (co)restriction morphisms map : E ≤ E' → … plus functoriality axioms. Kept as a concrete surface for constructions that read more clearly with explicit field access than with functor destructuring.

The two forms are provably equivalent, at increasing strength:

  • Type-level bijection Sheaf.equivPrimed : Sheaf X C ≃ Sheaf' X C (and cosheaf dual), with left_inv/right_inv closed by Sheaf.ofObject_toObject / Sheaf.toObject_ofObject (proved by cases-then-rfl — round-trip agrees on the nose).
  • Categorical equivalence Sheaf.equivPrimedEquiv : Sheaf X C ≌ Sheaf' X C (and cosheaf dual), where Sheaf' X C is promoted to a category via an explicit Sheaf'.Hom structure (an app-component family with a naturality square against map), and the unit/counit NatIsos reduce to eqToIso on the round-trip lemmas above.

Downstream code should PREFER the no-prime (functor) form — it composes with Mathlib's functor-category API for free; the primed form exists to bridge the paper's presentation for readers whose mental model is object-oriented. Any theorem stated for one form transports to the other along the categorical equivalence.

Equivariance data

The class GEquivariantCosheaf G X F (typeclass on a single cosheaf F) records the pointwise action data

act : ∀ (g : G) (E : X), F.obj (op E) ≅ F.obj (op (g • E))

as a family of isomorphisms (matching the paper's convention "$g_* : V_E \xrightarrow{\sim} V_{gE}$"), together with three axioms — act_map (naturality with cosheaf restrictions), act_one (identity of $G$ acts as $\mathbf 1$ modulo eqToHom for $1 \cdot E = E$), and act_mul (multiplicativity modulo eqToHom for $(g\cdot h)\cdot E = g\cdot(h\cdot E)$).

Why Iso and not just a morphism. For a Group G invertibility of act g follows abstractly, but packaging as Iso from the start gives downstream code direct access to .inv, avoiding rewrite-motive typechecking failures on rw [inv_one] when g⁻¹ appears in an eqToHom target type. The derived lemma GEquivariantCosheaf.act_one_inv records that (act 1 E).inv equals the eqToHom bridging W_{1 \cdot E} = W_E.

For §2.7 (Prop 2.7.2) we need $\Cosh_G(X, C)$ as a category (not just a predicate on individual cosheaves): the file GEquivCosheaf.lean supplies the bundled type GEquivCosheaf' G X C := (base : Cosheaf X C, equiv : GEquivariantCosheaf G X base) together with a Category instance whose morphisms are natural transformations of the underlying cosheaves commuting with act g E at every cell.
