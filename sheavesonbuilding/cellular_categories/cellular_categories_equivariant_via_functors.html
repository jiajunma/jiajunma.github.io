$G$-equivariant (co)sheaves as functors on $]X/G[$ resp.\ $[X/G]$

Given a cellular $G$-action on $X$ (Locally finite regular CW complex with cellular G-action), the two nominally independent structures — the poset (face relation) and the group action — are packaged together in the two transporter categories $]X/G[$ and $[X/G]$ (The transporter categories ]X/G[ and [X/G]). Every equivariant sheaf and cosheaf on $X$ arises as a functor on the appropriate one.

Statement

Proposition. For any category $\mathscr C$:

$$ \Sh_G(X, \mathscr C) \;\simeq\; \underline{\mathrm{Fun}}(\, ]X/G[,\; \mathscr C\, ) \qquad\text{and}\qquad \Cosh_G(X, \mathscr C) \;\simeq\; \underline{\mathrm{Fun}}(\, [X/G],\; \mathscr C\, ). $$

Equivalently, $\Cosh_G(X, \mathscr C) \simeq \underline{\mathrm{Fun}}(\, ]X/G[^{\mathrm{op}},\; \mathscr C\, )$.

Taking $G = \{e\}$ recovers $\Sh(X, \mathscr C) \simeq \underline{\mathrm{Fun}}(]X[, \mathscr C)$ and $\Cosh(X, \mathscr C) \simeq \underline{\mathrm{Fun}}([X], \mathscr C)$.

Sketch of the equivalence (sheaf case)

Given $(V, a) \in \Sh_G(X, \mathscr C)$, define $F :\, ]X/G[\, \to \mathscr C$ by

  • $F(E) := V_E$;
  • for $g \in \Hom_{]X/G[}(E, E')$ (i.e.\ $g \cdot E \preceq E'$), $F(g) := r^V_{g \cdot E,\, E'} \circ a^V_{g, E}$.

Functoriality ($F(h) \circ F(g) = F(hg)$ for composable $g : E \to E'$, $h : E' \to E''$) is a direct chase using the equivariance axiom of $a^V$ and transitivity of $r^V$.

Inverse. Given $F :\, ]X/G[\, \to \mathscr C$, set $V_E := F(E)$, $r^V_{E, E'} := F(e : E \to E')$ (the identity element $e \in G$ as a morphism $E \to E'$ whenever $E \preceq E'$), and $a^V_{g, E} := F(g : E \to g \cdot E)$.

Cosheaf case is dual: $F : [X/G] \to \mathscr C$ takes morphisms in the reverse direction, matching corestriction.

Corollary: stalk actions as endomorphism actions

Under the equivalence, the stalk action of $\Stab_G(E)$ on $V_E$ (a $G$-equivariant sheaf/cosheaf datum) is the endomorphism action $\End_{]X/G[}(E) \cong \Stab_G(E)$ on $F(E)$ (The transporter categories ]X/G[ and [X/G]).

Lean design notes

Full Lean signatures for all declarations below are auto-extracted from source at deploy time; see the Lean declarations section.

Design symmetry. Both GEquivSheaf' and GEquivCosheaf' extend the primed (object-form) base type — Sheaf' X C and Cosheaf' X C respectively — and inline the pointwise-iso equivariance data (act, act_map, act_one, act_mul). Field access is uniform on both sides: W.obj E, W.map h, W.act g E (no W.base.obj (op E) / W.equiv.act g E legacy anywhere).

Cosheaf side. The forward direction $\Cosh_G(X, \mathscr C) \to \Fun(\,]X/G[^{\mathrm{op}}, \mathscr C)$ is fully formalised in SheafOnBuilding.GEquivCosheafToFun — the building-block GEquivCosheaf'.mapOfG is composed of an object-form corestriction W.map hg followed by an inverse action (W.act g E').inv; multiplicativity and identity axioms are established, and the whole object-level toFunctor : GEquivCosheaf' G X C → (TransporterCat G X)ᵒᵖ ⥤ C is sorry-free.

The library is sorry-free after the underlying TransporterCat-abbrev → structure refactor (The transporter categories ]X/G[ and [X/G] Lean design note). Under the earlier abbrev encoding the type X carried two competing Category X instances (preorder-derived and the scoped TransporterCat.category); their Xᵒᵖ derivations produced non-defeq Hom types, so any term mixing Cosheaf X C = Xᵒᵖ ⥤ C (uses preorder) and (TransporterCat G X)ᵒᵖ ⥤ C (needs the scoped one) timed out isDefEq — even bumping synthInstance.maxHeartbeats to 400k did not help. Making TransporterCat a fresh structure gives it a unique Category instance and the elaboration goes through cleanly.

Cosheaf bridge Equivalence — done. Both directions of the categorical equivalence

GEquivCosheaf' G X C ≌ GEquivCosheaf G X C = GEquivCosheaf' G X C ≌ (TransporterCat G X)ᵒᵖ ⥤ C

are now in place in SheafOnBuilding.GEquivCosheafEquiv. Forward is GEquivCosheaf'.toFunctorFunctor lifting the object-level toFunctor to a functor between the two categories. Inverse is toGEquivCosheafFunctor, built from Functor.toGEquivCosheaf' on objects. The Functor.toGEquivCosheaf' construction takes a F : (TransporterCat G X)ᵒᵖ ⥤ C and recovers:

  • base := toTransporterCat.op ⋙ F : Xᵒᵖ ⥤ C — using the canonical inclusion toTransporterCat : X ⥤ TransporterCat G X which sends each face relation to the group element 1;
  • equiv.act g E built as an Iso from F.mapped transporter-cat morphisms ⟨g⟩ and ⟨g⁻¹⟩;
  • act_map, act_one, act_mul, and iso axioms all reduce to F.map_comp / F.map_id on transporter-cat compositions, verified via Subtype.ext on the underlying group elements.

Unit iso is component-wise identity NatTrans; counit iso ditto on F.obj (op E); the triangle identity holds by rfl after Category.id_comp. Packaged as GEquivCosheaf'.equivFunctor : GEquivCosheaf' G X C ≌ (TransporterCat G X)ᵒᵖ ⥤ C.

Sheaf side. Not started. Mechanically dual to the Cosheaf side: mapOfG uses restriction ∘ act; the sheaf version uses act ∘ restriction with the arrow direction reversed.

Consequences for the reduction

With the bridge Equivalence closed and the Cosheaf forward direction sorry-free, the two downstream reductions can be stated on either the object form (GEquivCosheaf') or the functor form (GEquivCosheaf), transported along the Equivalence. The functor form is currently used because both reductions plug directly into funCatEquivOfQFD and PXPrimeTransporterCat.toInducedTransporterCat_isEquivalence:

  • Reduction of G-equivariant cosheaves to a QFD delivers GEquivCosheaf.equivRestrictQFD : GEquivCosheaf G X C ≌ ((OnSubcomplex S)ᵒᵖ ⥤ C) via funCatEquivOfQFD.symm.
  • The category [X'/P] and its equivalence with the transporter category of G ×^P X' delivers GEquivCosheaf.equivInduction : GEquivCosheaf G (InducedSpace d) C ≌ ((PXPrimeTransporterCat d)ᵒᵖ ⥤ C) via Equivalence.congrLeft on PXPrimeTransporterCat.toInducedTransporterCat.op.

Composing either with GEquivCosheaf'.equivFunctor re-states these on the primed object form (issue #22 leftover).
