#

Yu's tame supercuspidal construction

[Yu 2001] introduces the generic cuspidal datum $(\vec G, (x, \{\iota\}), \vec r, \rho, \vec \phi)$ for tame reductive groups and constructs the associated supercuspidal representations via iterated Heisenberg–Weil twists.

⚠️ Important: Yu 2001 has a gap; use Fintzen 2021 for the affected proofs. Yu's proofs of Prop 14.1 and Thm 14.2 (and consequently several of the §12–14 intertwiner lemmas below) had a gap in the handling of certain sign characters across the twisted Levi tower. [Fintzen 2021] fixes the gap under an explicit hypothesis on $p$ (satisfied in all cases used in this KB); the statements are unchanged, but the proofs should reference Fintzen 2021 or the downstream [Dat–Fintzen 2026] reformulation, not Yu 2001 directly. See Fintzen 2021: correction to Yu's tame supercuspidal construction for details.

Lemmas / theorems from [Yu] that this paper uses (mostly in §10):

  • Lemma 9.3 — depth-shifting identity for $\hat \phi$;
  • Theorem 9.4 — two-term intertwiner identity, used in Two-term intertwiner I(φ_y, φ_x) = G_{x,s} G' G_{y,s} (Yu Thm 9.4 generalized);
  • Lemma 12.4 — dimension formula for $\Hom_{J_y \cap J_x}(\kappa_x, \kappa_y)$;
  • Lemma 12.5 — index identity feeding the dimension count;
  • Remark 12.7 — reduction of the Hom to isotypic blocks;
  • Lemma 13.6 — $V/V^+/V'$ index identity;
  • Lemma 13.7 — intersection factorization ${}^g K_{y,+} \cap K_{x,+} = ({}^g K^{(d-1)}{y, +} \cap K^{(d-1)}{x, +}) ({}^g J_y \cap J_x)$, used in the inductive intertwiner argument.

A modern recasting of all of these can be found in [AFMO2 §3], which is the more direct source for the data we use.

Dat–Fintzen parallel

[Dat–Fintzen 2026] (see Dat–Fintzen 2026: block decomposition + reduction to depth zero (tame)) re-derives most of the Yu lemmas in a cleaner, modular form built around their wild-inertia / idempotent-system framework. The following mapping is useful when looking up alternative statements or proofs:

Citation priority (revised after Fintzen 2021). For proofs of the §12–14 intertwiner lemmas (which include Yu Prop 14.1 and Thm 14.2), the priority is DF 2026 > Fintzen 2021 > Yu 2001: Yu's original proofs of these contain a gap (see Fintzen 2021: correction to Yu's tame supercuspidal construction), and the modern references reflect the corrected argument. Yu 2001 is kept only for historical notation alignment and for the statements of the lemmas.

For lemmas where Yu's proof is correct (e.g. Yu Lem 8.3 descent, Yu Lem 8.4 depth-shifting isomorphism, Yu Lem 9.3 $G'$-invariance, Yu Lem 13.7 intersection factorization), all three sources agree; DF gives the cleanest reformulation, so it remains the preferred reference for verification.

Specific KB nodes that benefit from the DF alternative source:

  • [[node:applications.tame_hypotheses_K]] — (K3) proof via MP convexity in each $G^{(i)}$ uses Yu Lem 8.4 + Cor 8.3; DF gives a more uniform statement.
  • Two-term intertwiner I(φ_y, φ_x) = G_{x,s} G' G_{y,s} (Yu Thm 9.4 generalized) — Yu Thm 9.4; DF Lem 2.6.6 is a cleaner alternative.
  • Hom(κ_x, κ_y)_{K∩K} one-dim and G^{(0)}-trivial (proves (E3)) — Yu Lem 12.4/12.5/13.6/13.7; DF §3.4 packages these.
  • Global intertwiner I(φ_y, φ_x) = K_x G^(0) K_y — Yu Lem 13.7 for the inductive step; DF lattice-index argument suffices.
